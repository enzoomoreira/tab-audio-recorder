13 - <audio> with faked mediaKeys (EME refusal)

Expected outcome: recording refused with "DRM/EME content cannot be captured"

We stub element.mediaKeys via Object.defineProperty so the DRM check in MediaElementHook treats this element as if it were EME-protected. Real DRM (Spotify, Apple Music) would set this via setMediaKeys(); the check in our code is a simple != null guard.
