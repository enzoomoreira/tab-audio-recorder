Improved capture reliability, recording management, and audio export.

- Recordings refresh automatically without resetting unchanged players or keyboard focus.
- Network capture validates its response and initial data before reporting success, allowing fallback when initialization fails.
- HLS/M3U playlists are excluded from raw audio capture.
- Web Audio capture selects connected, running contexts and reports ambiguous sources instead of choosing arbitrarily.
- WAV/MP3 encoding runs in a dedicated Worker. Conversions are queued and remain active when the manager closes.
- Export settings validate download paths and show a matching filename preview.
- Failed recording actions, including keyboard shortcuts, appear in the popup and toolbar badge.

All 79 unit tests passed, along with TypeScript, lint, and Mozilla package validation. Firefox integration checks exported five minutes to MP3 while another capture continued, verified the downloaded audio and WAV output, and completed a ten-minute MP3 export with the manager closed. These export checks used Firefox's simulated audio backend because the host audio device could not start, including without the extension.

WAV/MP3 conversion still decodes the full recording and can consume substantial memory. Original export avoids conversion. This release does not add an HLS client or mix multiple Web Audio contexts.

Install and receive signed updates through [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tab-audio-rec/). Mozilla approval and public availability may follow submission.
