# Tab Audio Recorder 0.1.2

This maintenance release fixes recording lifecycle, saving and interface reliability.

- The popup leaves "Saving..." when saving finishes and displays capture/storage errors.
- Audio remains saveable when playback ends before Stop is pressed.
- Armed capture handles competing frames, and navigation or an older save cannot
  overwrite the state of a new recording.
- Recording limits and stop timeouts use browser alarms across background suspension.
- IndexedDB save/delete wait for transaction commit.
- Playback, export, deletion, filtering and settings recover from failed or stale operations.

Validation: 79 unit tests and 12 Firefox integration tests passed. A separate
Firefox check saved and decoded audio after natural playback completion.

Install the signed extension from [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/tab-audio-rec/).
Mozilla publication is handled separately from this GitHub release; the store
shows the version currently available for installation.

The release workflow builds matching extension/source packages. Optional Mozilla
API submission can be enabled with repository secrets and a variable, as described
in [publishing instructions](../publishing.md#7-automated-release-workflow).
